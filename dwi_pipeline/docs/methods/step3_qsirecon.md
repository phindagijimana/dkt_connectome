# Step 3 — QSIRecon tractography

**Theory and methods** for diffusion reconstruction and tractography. Operational details: [Pipeline steps § Step 3](../pipeline_steps.md#step-3-qsirecon).

---

## Background

Preprocessed DWI (Step 1) encodes **local fiber orientation** through diffusion anisotropy. Tractography integrates these orientations into **3D streamlines** — curves that approximate white-matter pathways. Structural connectomics counts how many streamlines (or weighted streamlines) connect each pair of brain regions.

The default spec **`mrtrix_singleshell_ss3t_ACT-hsvs`** combines:

- **Single-shell SS3T-CSD** — fiber orientation distributions from one b-value shell
- **ACT** — anatomically constrained tractography using tissue priors
- **HSVS** — hybrid surface/volume segmentation for accurate cortical boundaries
- **SIFT2** — optional streamline weighting for quantitative density matching

---

## Diffusion modeling: SS3T-CSD

**Constrained spherical deconvolution (CSD)** estimates the **fiber orientation distribution (FOD)** per voxel, resolving crossing fibers better than single-tensor DTI (Tournier et al. 2019).

**SS3T** (single-shell, three-tissue) fits separate response functions for **WM, GM, and CSF** when only one non-zero b-value is available (Jeurissen et al. 2014). This separates anisotropic WM signal from isotropic partial-volume contamination — critical at the cortical ribbon and near ventricles.

| Token in spec name | Meaning |
|--------------------|---------|
| `mrtrix` | MRtrix3 backend |
| `singleshell` | One b-value shell (default b = 1000) |
| `ss3t` | Single-shell 3-tissue CSD |
| `ACT-hsvs` | ACT using HSVS-derived 5TT image |

---

## Five-tissue-type (5TT) image

ACT requires a **5TT** image at each integration step: cortical GM, subcortical GM, WM, CSF, and pathological/other tissue volumes (Smith et al. 2012).

**HSVS** (Hybrid Surface/Volume Segmentation; Smith et al. 2020) builds the cortical ribbon from FreeSurfer **white/pial surfaces** (Step 2) combined with subcortical volumes — more accurate than volume-only segmentation at thin sulci.

Alternative without Step 2 surfaces: `mrtrix_singleshell_ss3t_ACT-fast` (FSL FAST 5TT). Not the pipeline default.

---

## Anatomically constrained tractography (ACT)

At each streamline step, ACT checks the **tissue class** under the propagation front (Smith et al. 2012):

| Transition | Action |
|------------|--------|
| WM → WM | Continue |
| WM → cortical GM | **Terminate** (valid endpoint) |
| WM → subcortical GM | **Terminate** |
| WM → CSF | **Discard** (invalid) |

This reduces false positives — streamlines floating in CSF or jumping across sulci — yielding more biologically plausible pathways for connectome construction.

Seeds are typically placed in **white matter** voxels. ~10 million streamlines are generated by default (iFOD2 algorithm in MRtrix3 `tckgen`).

---

## SIFT2 weights

**SIFT2** (Smith et al. 2015) assigns a non-negative weight **w(s)** to each streamline so the weighted streamline density matches FOD-derived fiber density across the brain.

| Weighting | Step 4 default | When to use SIFT2 |
|-----------|----------------|-------------------|
| Streamline counts | Yes | Simple group comparisons, count-based graphs |
| SIFT2 weights | Optional (`--connectome-weighting sift2`) | Quantitative density interpretation |

SIFT2 weights are always computed in Step 3 and stored alongside the tractogram; Step 4 and Step 4.5 can optionally use them.

## What DKT Connectome runs

| Item | Value |
|------|-------|
| Container | `pennlinc/qsirecon:1.2.1` (`qsirecon.sif`) |
| Spec | `mrtrix_singleshell_ss3t_ACT-hsvs` |
| Requires | FreeSurfer subject tree from Step 2 (for HSVS) |
| Input DWI | QSIPrep `desc-preproc_dwi` on `dwiref` grid |

### Key outputs

```text
qsirecon_single_run_output/sub-<ID>/ses-<Y>/dwi/
  *_streamlines.tck.gz              # ~10M streamlines in world coordinates
  *_sift2_streamlineweights.csv     # optional weighting for connectome
```

Optional atlas connectomes (e.g. 4S156) run inside QSIRecon when `QSIRECON_ATLASES` is set — independent of Step 4's subject-native DKT connectome.
